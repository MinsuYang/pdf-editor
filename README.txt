━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이 프로그램은 제가 직접 제작한 PDF 편집 툴입니다.
악성코드나 바이러스가 포함되어 있지 않습니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ 실행이 안 될 경우 ]

Windows Defender 또는 회사 보안 정책에 의해
출처 불명 프로그램으로 분류되어 차단될 수 있습니다.

해결 방법:
1. PDF편집기.exe 파일을 우클릭
2. [속성] 선택
3. 하단 "보안" 항목에서 [차단 해제] 체크 후 확인
4. 다시 실행

위 방법으로도 실행되지 않는 경우,
pdf_editor.py 파이썬 소스코드를 직접 실행하는 방법도
동봉되어 있으니 참고해주세요.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ 소스코드 실행 방법 ]

1. Python 3.x 설치 (python.org)
2. 라이브러리 설치:
   pip install pypdf pymupdf tkinterdnd2 pillow
3. 실행:
   python pdf_editor.py
